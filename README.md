# hxyfront-62012 纺织染整小样管理

源提示词编号：7

我需要一个纺织染整实验室的小样管理前端系统，可以记录面料成分、克重、染料配方、浴比、温度曲线、保温时间、后整理方式、色差值和评审结果。页面需要有小样批次列表、配方比例展示、Lab色差对比、工艺曲线摘要和按客户订单筛选。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62012

## 染杯清洗隔离流程

在小样台基础上新增「染杯清洗隔离」业务，代码按三层拆分为三个业务文件：

- `src/cleaning/cleaningRules.ts` —— **规则层**（纯函数）：开染前校验、放行校验、按序重算；
- `src/cleaning/cleaningStore.ts` —— **存储层**：批次 / 染杯 / 回执 / 审计单一数据源，localStorage 持久化与订阅；
- `src/cleaning/CleaningConsole.tsx` —— **界面层**：批次排产列表、染杯清洗队列、单杯履历与回执管理。

业务规则：

1. 开染前校验染杯最近一次清洗回执（24h 有效）、残留色度（≤ 0.5）和上一批色深；
2. 回执过期、残留超限或深色后直接排浅色，只能转「待清洗」，不得占用染杯；
3. 清洗必须换人复核（清洗人 ≠ 复核人），连续两次冲洗色度达标才放行并签发回执；
4. 补录或更正回执：旧版回执标记失效留档，相关未开染排产与已完成批次评审失效，全部在制排产按排产顺序重新占杯；
5. 排产列表、染杯队列、单杯履历订阅同一数据源并持久化，刷新后保持一致；
6. 已开染 / 染色中的排产锁定，不参与重算。

类型检查：`npm run typecheck`
