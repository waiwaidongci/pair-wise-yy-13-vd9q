# hxyfront-62012 纺织染整小样管理

源提示词编号：7

我需要一个纺织染整实验室的小样管理前端系统，可以记录面料成分、克重、染料配方、浴比、温度曲线、保温时间、后整理方式、色差值和评审结果。页面需要有小样批次列表、配方比例展示、Lab色差对比、工艺曲线摘要和按客户订单筛选。

## 技术栈

React + Vite + TypeScript

## 染杯清洗隔离流程（`src/cleaning/`，三个业务文件分层）

- `rules.ts` 规则层（纯函数）：开染前三验（最近清洗回执 24h 有效期、残留色度 ≤ 0.50、上一批深色后不得直接排浅色）、连续两次冲洗达标、清洗人与复核人不得同人、补录/更正影响面计算与队列重排序号。
- `storage.ts` 存储层：localStorage 持久化（刷新后一致）、排产/开染/完工/清洗/放行/补录更正等动作、回执版本链旧版留档、级联失效与按新顺序重算、单杯事件履历。
- `CleaningStation.tsx` 界面层：小样批次列表（订单/色深筛选、拦截原因、评审登记/重评）、染杯队列（回执有效期倒计时、冲洗登记、换人复核放行）、单杯履历（版本链、补录/更正影响面预览、事件流），三视图共用同一 store。

未过三验的排产只能转“待清洗隔离”，不占染杯；回执补录或更正后，相关在途排产失效、已完成批次评审失效待重评，旧版回执只读留档。
